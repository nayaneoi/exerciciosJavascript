🚀 Exercícios JavaScript

Repositório com exercícios práticos de JavaScript (e um pouco de lógica de programação), organizados por temas.
O objetivo é reforçar conceitos fundamentais através de exemplos simples e desafios progressivos.

📂 Estrutura do repositório

Cada pasta contém exercícios focados em um assunto específico:

Pasta	Conteúdo
exercicioVariaveiseOperadores	Declaração de variáveis, tipos e operadores
lacosCondicionais	if, else, switch e lógica condicional
LacosRepeticaoArrays	for, while, loops e manipulação de arrays
Collections	Map, Set e coleções em JavaScript
EstruturadeDados	Filas, pilhas, listas e conceitos básicos de estrutura de dados

Dentro de cada pasta, os arquivos seguem exemplos e atividades comentadas para facilitar o estudo.

🧠 Conceitos praticados

✔ Variáveis e operadores
✔ Estruturas condicionais
✔ Laços de repetição
✔ Manipulação de arrays
✔ Uso de collections (Map/Set)
✔ Estruturas de dados básicas

▶️ Como executar os exercícios

1️⃣ Certifique-se de ter Node.js instalado
2️⃣ Navegue até a pasta do exercício:

cd NomeDaPasta


3️⃣ Execute o arquivo desejado:

node arquivo.js
